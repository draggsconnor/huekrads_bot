# HueKrads — Экспедиции

**Телеграм-бот для idle/RPG игры «Экспедиции»**

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и проставьте свой BOT_TOKEN из @BotFather.

3. Запустите:
```bash
python -m src.main
```

Или через Docker:
```bash
docker build -t huekrads-bot .
docker run --env-file .env huekrads-bot
```

## Структура игры

**Подвиги**
Вместо традиционной прокачки персонаж развивается через подвиги — достижения, которые открывают доступ к новым механикам и наградам. Стартовый подвиг «REGISTRATION» доступен сразу.

**Экспедиции**
Игрок может отправить свою тулову в экспедиции для добычи ресурсов и поиска предметов. Экспедиции различаются по требованиям, риску и времени.

**Корпорация и биржа**
Игроки управляют корпорацией, покупают и продают акции. Цены меняются каждый ход.

**Походы волчьей стаи**
Краткосрочные альянсы до 5 человек с общим изгнанием.

**PvP**
Возможность атаковать других игроков и участвовать в дуэлях.

**Медали за DEFINITION**
DEFINITION полностью удалён из прямой прокачки, но его всё ещё можно купить за медали через `/medals`.

## Файлы проекта

- `src/main.py` — точка входа
- `src/handlers.py` — обработчики команд
- `src/models.py` — модели данных
- `src/combat.py` — боевые расчёты
- `src/scheduler.py` — планировщик событий
- `src/storage.py` — хранение данных
- `src/config.py` — константы и конфигурация
- `docs/achievements.md` — Лор и достижения
- `docs/CHANGELOG.md` — История изменений
- `docs/JOURNAL.md` — Журнал разработки

## Логи

После запуска текущая сессия записывается в `journal/session_<timestamp>.md` — боевая сводка, смерти, уровни и найденные предметы.
