# HueKrads — Экспедиции

**Телеграм-бот idle/RPG-игры «Экспедиции»**: игрок отправляет гнома в экспедицию, а по возвращении получает ресурсы, опыт и отчёт о случайной стычке с мобом или боссом.

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и проставьте свой BOT_TOKEN из @BotFather.

3. Запустите:
```bash
python bot.py
```

Или через Docker:
```bash
docker compose up -d --build
```

Подробнее о деплое — в [DEPLOY.md](DEPLOY.md).

## Команды

| Команда | Описание |
|---------|----------|
| /start | Список локаций экспедиции |
| /adventure | Список локаций экспедиции |
| /adventure_stats | Статистика экспедиции |
| /adventure_inventory | Инвентарь экспедиции |
| /help | Справка |

Ответы `/help`, `/adventure_stats`, `/adventure_inventory` и финальные отчёты экспедиции бот убирает через минуту после отправки. Выключатель per-чат — флаг `auto_delete_enabled` в таблице `chat_settings` (по умолчанию включён). Меню локаций, стартовые сообщения и сообщения боя не удаляются.

## Как устроена игра

**Экспедиции.** Через `/adventure` игрок выбирает локацию. У каждой локации есть минимальный уровень (`requirements.min_level`), длительность, таблица ресурсов с шансами дропа и список боссов. Активна одна экспедиция за раз; досрочно гнома можно вернуть кнопкой (без наград). Результат приходит в тот же чат, где экспедиция была запущена.

**Энкаунтеры и интерактивный бой.** Внутри экспедиции в случайный момент может появиться враг (шанс — `encounter_chance` локации; первым делом бросаются боссы локации по их `encounter_chance`, затем специфичные мобы, затем редкость common/uncommon/rare). Начинается бой с кнопками: каждый раунд — две фазы по 10 секунд, в первой гном выбирает зону атаки (голова/торс/хуй), во второй — зону блока. Атака попадает, если её зона отличается от блока врага (2/3); если блок гнома совпал с атакой врага, удар принят на блок (1/3), иначе — урон (по тиру врага, 25–60 HP). Чтобы победить, нужно выбить 1–3 попадания (по тира врага); победное попадание гасит ответный удар. Не успел за 10 секунд — зона выбирается случайно, поэтому бой всегда завершается даже без участия игрока. Поражение прерывает экспедицию досрочно: гном возвращается с 1 HP, без опыта, с минимальным лутом. Победивший получает XP по тиру, +20 HP и с шансом 50% предмет из общего каталога (`global_pool.json`; боссы — свой лут и бонусный XP). Бои переживают рестарт бота: джоба-сторож `battle_watcher_job` доводит фазы и запускает пропущенные энкаунтеры. Полная спецификация механики боя — [docs/BATTLE.md](docs/BATTLE.md).

**Прогресс.** XP за победы в боях повышает уровень (порог уровня N: `50 + N×50`), каждый уровень добавляет +20 к максимальному HP и немного лечения. Уровни открывают локации с более высокими требованиями.

**Ресурсы и инвентарь.** Добытое складывается в инвентарь (`/adventure_inventory`), прогресс виден в `/adventure_stats`.

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| BOT_TOKEN | Токен бота от @BotFather | (обязательно) |
| ADMIN_IDS | ID администраторов через запятую | - |
| PLAYER_DATA_PATH | Путь к JSON с данными игроков | `persist/adventure_player_data.json` |
| DATABASE_PATH | Путь к SQLite-базе | `persist/bot_database.db` |

## Структура проекта

```
bot.py                              # точка входа: команды, джобы экспедиций
config.py                           # чтение .env
database.py                         # SQLite-слой (наследие старых режимов бота)
text_resources.py                   # загрузчик текстов из texts/*.yaml
handlers/
  adventure.py                      # экспедиции: локации, таймеры, ресурсы, итоги
  battle.py                         # интерактивный бой: раунды, зоны атаки/блока
  adventure_expiration_checker.py   # страховочная джоба завершения экспедиций
  utils.py                          # общие хелперы, глобальный error handler
texts/                              # пользовательские тексты (YAML: menu, common, adventure, battle, media)
data/adventure/                     # локации, мобы, пул предметов (JSON)
persist/                            # данные игроков (создаётся при запуске)
docs/JOURNAL.md                     # журнал разработки
docs/BATTLE.md                      # спецификация механики боя при энкаунтерах
CHANGELOG.md                        # история изменений
tests/                              # pytest-тесты
src/                                # экспериментальная модульная версия (не используется ботом)
```

Тексты вынесены в YAML и загружаются через `text_resources.get_text("домен.ключ", **плейсхолдеры)` — новые пользовательские строки добавляйте туда, а не в код.

## Логи

Бот пишет логи в stdout/stderr (уровень INFO). Чтобы собрать их в файл:

```bash
python bot.py > bot_output.log 2>&1
```
