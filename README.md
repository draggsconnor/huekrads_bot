# HueKrads — Экспедиции

**Телеграм-бот idle/RPG-игры «Экспедиции»**: игрок отправляет гнома в экспедицию, а по возвращении получает ресурсы, опыт и отчёт о случайной стычке с мобом или боссом.

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и проставьте свой BOT_TOKEN из @BotFather.

3. Запустите:
```bash
python bot.py
```

Или через Docker:
```bash
docker compose up -d --build
```

Подробнее о деплое — в [DEPLOY.md](DEPLOY.md).

## Команды

| Команда | Описание |
|---------|----------|
| /start | Список локаций экспедиции |
| /adventure | Список локаций экспедиции |
| /adventure_name | Назвать гнома (один раз навсегда, после — «Имя (username)» всюду) |
| /adventure_equipment | Снаряжение гнома: кнопки «НАДЕТЬ/СНЯТЬ», живёт 5 минут |
| /adventure_stats | Статистика экспедиции |
| /adventure_inventory | Инвентарь экспедиции |
| /adventure_huecrab | Карточка хуекраба |
| /adventure_saray | Сарай хуекрабов |
| /admin_gnome_name `<uid> <имя>` | ⚙️ админ: принудительно задать имя гнома (CAS в обход) |
| /admin_gnome_reset `<uid>` | ⚙️ админ: сбросить имя гнома |
| /help | Справка |

Ответы `/help`, `/adventure_stats`, `/adventure_inventory` бот убирает через минуту после отправки (команда игрока — вместе с ними; для этого боту нужны права на удаление чужих сообщений — без прав команда просто останется). Через **две минуты** живут: `/adventure` (меню локаций + сама команда игрока), финальные отчёты экспедиции и отчёты боя (победа/поражение). Выключатель per-чат — флаг `auto_delete_enabled` в таблице `chat_settings` (по умолчанию включён). Стартовые сообщения экспедиции не удаляются.

## Как устроена игра

**Экспедиции.** Через `/adventure` игрок выбирает локацию. У каждой локации есть минимальный уровень (`requirements.min_level`), длительность, таблица ресурсов с шансами дропа и список боссов. Активна одна экспедиция за раз; досрочно гнома можно вернуть кнопкой (без наград). Результат приходит в тот же чат, где экспедиция была запущена.

**Энкаунтеры и интерактивный бой.** Внутри экспедиции в случайный момент может появиться враг (шанс — `encounter_chance` локации, обе действующие — 90%; первым делом бросаются боссы локации по их `encounter_chance`, затем специфичные мобы, затем редкость common/uncommon/rare). Начинается бой с кнопками: каждый раунд — две фазы по 10 секунд, в первой гном выбирает зону атаки (голова/торс/хуй), во второй — зону блока. Атака попадает, если её зона отличается от блока врага (2/3), и наносит цифровой урон (голые руки 20, топоры 35–50, крит ×2); у врага HP (обычный 40, босс до 140) — враг падает при HP 0, победное попадание гасит ответный удар. Если блок гнома не совпал с атакой врага (1/3), гном получает урон по тиру врага (25–60) минус защиту брони на этой зоне. Не успел за 10 секунд — зона выбирается случайно, поэтому бой всегда завершается даже без участия игрока. Поражение прерывает экспедицию досрочно: гном возвращается с 1 HP, без опыта, с минимальным лутом. Победивший получает XP по тиру, +20 HP и с шансом 50% предмет из общего каталога (`global_pool.json`; боссы — свой лут и бонусный XP). Бои переживают рестарт бота: джоба-сторож `battle_watcher_job` доводит фазы и запускает пропущенные энкаунтеры. Полная спецификация механики боя — [docs/BATTLE.md](docs/BATTLE.md).

**Снаряжение.** Три группы слотов: 🗡 оружие (урон/крит/копание/шахтный бонус), 🛡 зоновая броня — 🧢 шапка, 👕 рубаха, 👖 портки каждая гасит часть урона в свою зону, 🎪 талисман (докидка лута, оберег при поражении). Экипировка копится в `equipment` игрока и уходит в бой снапшотом; пустые слоты честно обозначаются «нихуя». Каталог эффектов — `global_pool.json → gear`; кузня (крафт/надевание) — следующая итерация. Подробно — [docs/BATTLE.md §7](docs/BATTLE.md).

**Прогресс.** XP за победы в боях повышает уровень (левелап — фиксированные 100 XP за любой уровень), каждый уровень добавляет +20 к максимальному HP и немного лечения. В `/adventure_stats` видно, сколько XP осталось до левелапа. Уровни открывают локации с более высокими требованиями.

**Ресурсы и инвентарь.** Добытое складывается в инвентарь (`/adventure_inventory`), прогресс виден в `/adventure_stats`. Фрукты съедобны: кнопка «ИСПОЛЬЗОВАТЬ» открывает пикер с выбором конкретного фрукта (эффект виден на кнопке). Лечение по редкости: common +40, uncommon +70, смоляное яблоко +25, rare +100 (сверх `max_hp` срезается). Во время боя есть нельзя; окно пикера — 5 минут, потом сообщение чистится по общим правилам.

**Питомцы.** 🥚 Яйцо питомца падает пачкой 2–3 шт за бросок (шанс тестово 99%) и вылупляется кнопкой «ВЫЛУПИТЬ» в инвентаре: новый хуекраб заменяет старого, старый уезжает в **САРАЙ** (`/adventure_saray` — жилой хуекрабов, кнопка «ВЫБРАТЬ» меняет экипированного вне боя; качается только экипированный). Виды — равный шанс (по 19%), 👑 Королевский реже (5%); краб получает XP за каждый бой (победа — как гном, поражение +5) и растёт по уровням (порог `50 × уровень`); что даст уровень — обсуждается. Карточка — `/adventure_huecrab` (описание, перки, уровень); у неназванного — кнопка «✒️ ДАТЬ ИМЯ» (бот ждёт имя следующим сообщением), либо команда `/adventure_huecrab_name <имя>`; каждому крабу имя даётся один раз. Участие краба видно в отчётах боя: XP напарника в поражении и победе, заслуги перков (докидка лута, щедрый дроп, сбор при поражении) — отдельными строками, панцирь и Соглядай — в хронике и подсказке. Розыгрыш видов и цифры — в [docs/BATTLE.md §13](docs/BATTLE.md).

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|

| ADMIN_IDS | ID администраторов через запятую | - |

## Структура проекта

```
bot.py                              # точка входа: команды, джобы экспедиций
config.py                           # чтение .env
database.py                         # SQLite-слой (наследие старых режимов бота)
text_resources.py                   # загрузчик текстов из texts/*.yaml
handlers/
  adventure.py                      # экспедиции: локации, таймеры, ресурсы, итоги
  battle.py                         # интерактивный бой: раунды, зоны атаки/блока
  adventure_expiration_checker.py   # страховочная джоба завершения экспедиций
  utils.py                          # общие хелперы, глобальный error handler
texts/                              # пользовательские тексты (YAML: menu, common, adventure, battle, media)
data/adventure/                     # локации, мобы, пул предметов (JSON)
persist/                            # данные игроков (создаётся при запуске)
docs/JOURNAL.md                     # журнал разработки
docs/BATTLE.md                      # спецификация механики боя при энкаунтерах
CHANGELOG.md                        # история изменений
tests/                              # pytest-тесты
src/                                # экспериментальная модульная версия (не используется ботом)
```

Тексты вынесены в YAML и загружаются через `text_resources.get_text("домен.ключ", **плейсхолдеры)` — новые пользовательские строки добавляйте туда, а не в код.

## Логи

Бот пишет логи в stdout/stderr (уровень INFO). Чтобы собрать их в файл:

```bash
python bot.py > bot_output.log 2>&1
```
