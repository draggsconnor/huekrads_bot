# HueKrads Bot

Telegram-бот для финансовой игры в жанре idle/кликер.

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и проставьте свой BOT_TOKEN из @BotFather.

3. Запустите:
```bash
python main.py
```

Или через Docker:
```bash
docker build -t huekrads-bot .
docker run --env-file .env huekrads-bot
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| BOT_TOKEN | Токен бота от @BotFather | (обязательно) |
| ADMIN_IDS | ID администраторов через запятую | - |

## FAQ

- Бои идут offline: бой начинается после нажатия, результат приходит через заданное время.
- DEFINITION полностью удален: персонаж теперь собирает статистику подвигами.
- Покупка DEFINITION через /medals.
- Для помощи альпийцу предметы тратятся, но начисляют ценные награды.
- Волчья стая — краткосрочные альянсы до 5 человек с общим изгнанием.
