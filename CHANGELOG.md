## [Unreleased]

### Added
- Интерактивный бой при энкаунтерах во время экспедиции: раунды с фазами атаки/блока через inline-кнопки (голова/торс/хуй), 10 секунд на фазу; таймаут автоматически выбирает случайную зону, так что бездействующий бой всегда доводится до конца
- Энкаунтер случается в случайный момент внутри таймера экспедиции по `encounter_chance` локации (раньше — захардкоженные 99% при завершении)
- Боссы входят в ту же интерактивную систему через `battle`-параметры в locations.json; урон/число попаданий по тирам — из `battle_defaults` в mobs.json
- 50% дроп предмета из общего каталога при победе над мобом; каталог заведён в global_pool.json
- Сторож `battle_watcher_job` (10 с): докручивает фазы боёв после рестарта бота и запускает пропущенные энкаунтеры
- Поражение в бою прерывает экспедицию: гном возвращается с 1 HP, без опыта, с одним ресурсом при шансе 25%; победа — XP по тиру, лечение +20, журнал раундов в отчёте
- Уровни: XP повышает уровень (порог `50 + N×50`), каждый уровень даёт +20 max HP и немного лечения
- Тексты вынесены в YAML: кнопки и состояния экспедиции — texts/adventure.yaml, бой — texts/battle.yaml, `/help` — texts/menu.yaml
- Тесты: атомарное завершение экспедиции, боевая логика, стейт-машина боя, прокачка (62 всего)
- Структура проекта с каталогами `docs/` и `journal/`

### Changed
- Завершение экспедиции атомарно (`finish_expedition` + claim-блокировка): награды выдаются ровно один раз, кто бы ни сработал первым — таймер `job_queue`, страховочная джоба или клик игрока
- `finish_expedition` больше не ведёт бои: только ресурсы, уровни и итоговый отчёт из журнала боёв
- Завершение экспедиции откладывается, пока идёт бой; досрочный возврат гнома гасит и бой, и джобы боя/энкаунтера
- Просроченная экспедиция завершается сразу при открытии меню локации (раньше — молчаливо сбрасывалась без наград)
- Победа без ресурсов больше не считается провалом экспедиции
- В статистику экспедиций пишутся `wins`/`total_fights` по итогам боёв

### Fixed
- Гейт минимального уровня локации читал несуществующее поле `required_level` (всегда 1) — теперь берётся `requirements.min_level`
- Специфичные мобы локаций никогда не спавнились: код искал их в несуществующем ключе `mobs` в mobs.json — теперь читается реальный ключ `specific_mobs`
- README приведён к фактической архитектуре: точка входа `bot.py`, реальные команды и механики

### Removed
- Мёртвый дубликат расчёта экспедиции `calculate_expedition_result`
- Авто-бой при завершении экспедиции (`_resolve_encounter_fight`) — заменён интерактивным боем

## [0.4.0] - 2026-10-07

### Added
- Полная миграция: `bot.py` → `src/` (main, models, config, handlers, combat, storage, scheduler)
- Баланс undead: skeleton warrior (120→90 HP), zombie brute (200→150 HP), necromancer (100), ghost (60)
- Система достижений с 20+ ачивками + прогресс-бар
- Scheduler на asyncio вместо threading
- Docker multi-stage + healthcheck + non-root
- README с диаграммами, CHANGELOG, Dev Journal

### Changed
- Архитектура: монолитный bot.py → модульная структура src/
